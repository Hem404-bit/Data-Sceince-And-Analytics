# Sales Data Analysis Report

## Overview

This report is based on a small sales dataset containing 100 records. I used Python and Pandas to load the CSV file, inspect the data, and perform some basic sales analysis.

The main purpose of this analysis is to understand the sales data and practice common Pandas operations such as selecting columns, calculating summary statistics, and grouping data.

## Dataset

The dataset is stored in `sales_data.csv`.

It contains the following 7 columns:

| Column | Description |
|---|---|
| Date | Date on which the sale was recorded |
| Product | Product sold |
| Quantity | Number of units sold |
| Price | Price associated with the sale |
| Customer_ID | Unique customer identifier |
| Region | Sales region |
| Total_Sales | Total sales amount for the record |

There are **100 rows** in the dataset.

## Tools Used

- Python
- Pandas
- VS Code
- CSV dataset

## Data Loading

I loaded the dataset using Pandas:

```python
import pandas as pd

df = pd.read_csv("sales_data.csv")
```

After loading the file, I displayed the DataFrame to check whether the data was imported correctly.

## Initial Data Inspection

I used the following commands to understand the structure of the dataset:

```python
print(df.head())
print(df.shape)
print(df.columns)
print(df.info())
```

The dataset contains **100 rows and 7 columns**.

The first few records showed sales for products such as phones, headphones, and laptops, along with the quantity, price, customer, region, and calculated total sales.

## Sales Analysis

### Total Revenue

The total sales amount can be calculated using:

```python
total_revenue = df["Total_Sales"].sum()
print("Total Revenue:", total_revenue)
```

This gives the total revenue represented by all 100 sales records.

### Average Sale

To find the average value of a sale:

```python
average_sales = df["Total_Sales"].mean()
print("Average Sales:", average_sales)
```

This is useful for getting an idea of the typical sales value in the dataset.

### Highest and Lowest Sale

I also checked the maximum and minimum sales values:

```python
highest_sale = df["Total_Sales"].max()
lowest_sale = df["Total_Sales"].min()

print("Highest Sale:", highest_sale)
print("Lowest Sale:", lowest_sale)
```

These values help identify the range of sales amounts in the dataset.

## Product-Level Analysis

Sales can also be grouped by product:

```python
product_sales = df.groupby("Product")["Total_Sales"].sum()
print(product_sales)
```

This allows me to compare the total sales generated by each product.

I can also check how many units of each product were sold:

```python
product_quantity = df.groupby("Product")["Quantity"].sum()
print(product_quantity)
```

This provides a different view of product performance because a product may have a high number of units sold without necessarily generating the highest revenue.

## Regional Analysis

I used the `Region` column to compare sales between different regions:

```python
region_sales = df.groupby("Region")["Total_Sales"].sum()
print(region_sales)
```

This helps identify how sales are distributed across the regions in the dataset.

## Observations

From the initial inspection and analysis:

- Grouping by `Product` helps compare products based on revenue and quantity sold.
