# Week 2 - Student Grading System

## Project Description

This project is a simple Python program that takes a student's name and marks, calculates the grade, and displays an encouraging message.

The program also validates the marks to make sure the user enters a value between 0 and 100.

## Objectives

- Take student name as input
- Take marks between 0 and 100
- Validate user input
- Calculate the student's grade
- Display an encouraging message
- Handle invalid inputs using a while loop

## Grading System

| Marks | Grade |
|-------|-------|
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| 0 - 59 | F |

## Concepts Used

- Python functions
- if-elif-else statements
- while loop
- User input
- Input validation
- Exception handling
- f-strings
